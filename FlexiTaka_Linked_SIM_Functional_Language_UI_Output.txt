1. LINKED SIM FEATURES IMPLEMENTED
--------------------------------------------------------------------------------
- Authoritative Data Source:
  * Customer's linked SIMs are retrieved strictly from `GET /api/v1/user/sims` via `api.getLinkedSims()`.
  * Only SIM cards with status === "VERIFIED" are eligible and displayed in shortcut selectors (`verifiedSims = linkedSims.filter(s => s.status === "VERIFIED")`). Unverified SIMs or pending verifications are strictly excluded.
  * Zero operator tokens, PINs, or credentials are exposed in client-side code, state, or DOM elements. Backend remains the authoritative validator.

- Cash Out Integration (`/app/cashout`):
  * "Use Linked SIM" / "আমার যুক্ত সিম (Saved SIMs)" selector card appears dynamically when authenticated customers have one or more verified SIMs.
  * Each chip displays: Operator badge (GP / ROBI / BANGLALINK), formatted phone number, custom label (if set), live/cached balance (৳), and verified checkmark.
  * Selection Action:
    - Auto-fills source phone number and operator code.
    - Queries `api.getLiveBalance(sim.phone)` asynchronously (`/api/v1/operators/balance/live`).
    - If operator session is active and valid, sets live balance and marks phone as verified.
    - If operator session is expired or requires authentication, the error is safely caught and verified status is cleared (`setVerifiedPhone(null)`). When the customer continues to order placement, the standard operator OTP verification modal (`OtpVerificationModal`) is seamlessly triggered.
    - Provides a "+ অন্য নম্বর লিখুন" / "+ Enter other number" shortcut to clear selection and manually enter any arbitrary SIM number.
    - If the customer manually edits the phone number input, the linked SIM selection is automatically cleared.

- Recharge Integration (`/app/recharge`):
  * Quick "My SIM" / "আমার নম্বর (My SIM)" chip selector displayed prominently above the recipient details stage for authenticated customers with verified SIMs.
  * Selection Action:
    - Instantly auto-fills recipient mobile number and operator.
    - Smoothly transitions focus to the recharge amount input for fast checkout.
    - Allows clear toggle via "+ অন্য নম্বরে রিচার্জ করুন" / "+ Recharge another number" to enter any recipient number.
    - Manual phone editing automatically deselects the chip.
