# FlexiTaka API Contract for Clients (Web & Mobile)

**Version**: 1.0.0 (MVP Baseline)  
**Authoritative Backend Origin**: `https://flexitaka.online`  
**API Base URL**: `https://flexitaka.online/api/v1`  
**Customer Website Origin**: `https://flexitaka.com`

---

## 1. Golden Rules for Clients

1. **Clients Display Server Results**: The client UI must never independently calculate 20% or 5% fees/discounts. All money amounts, fees, and payouts displayed in checkout summaries MUST come from server quote endpoints.
2. **Standard Status Enums**: Clients must use exact backend status enums. Never rename statuses (e.g. do not invent "Done" or "Pending").
3. **Optional Account Flow**: Registration/login is completely optional for basic transactions. Guests are identified by `X-Guest-Session-ID`.
4. **Idempotency**: All money-creating POST requests should send an `Idempotency-Key` header (e.g. UUID v4). Repeated requests with the same key safely return the previously generated order without duplication.
5. **No Direct Database Access**: Clients interact exclusively through HTTPS REST endpoints.

## 2. Standard API Response Structure

### Success Response
```json
{
  "success": true,
  "data": { ... },
  "request_id": "8f3b20e1-0c4a-49a3-93d1-447596ad75e2"
}
```

### Error Response
```json
{
  "success": false,
  "error": {
    "code": "INVALID_AMOUNT",
    "message": "Cash Out amount must be between ৳50.00 and ৳50000.00",
    "details": null
  },
  "request_id": "8f3b20e1-0c4a-49a3-93d1-447596ad75e2"
}
```

## 3. Standard HTTP Headers

| Header | Description | Example |
|--------|-------------|---------|
| `Authorization` | Bearer token for authenticated users or staff | `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...` |
| `X-Guest-Session-ID` | Ephemeral guest session identifier | `FT-G-108249` |
| `Idempotency-Key` | Client-generated unique UUID to prevent double-submissions | `9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d` |
| `X-Request-ID` | Correlation ID generated by backend or client | `c56a4180-65aa-42ec-a945-5fd21dec0538` |

## 4. Master Enums

### Operators
- `GP` (Grameenphone)
- `ROBI` (Robi Axiata)
- `BANGLALINK` (Banglalink)

### Cash Out Statuses
- `REQUESTED`
- `WAITING_FOR_TRANSFER` (Receiving SIM shown to user)
- `TRANSFER_RECEIVED` (User submitted reference)
- `UNDER_VERIFICATION` (Staff verifying transfer)
- `APPROVED` (Transfer confirmed, ready for payout)
- `PAYOUT_PROCESSING` (Payout in progress)
- `COMPLETED` (Payout sent, order finished)
- `REJECTED` (Invalid transfer / rejected by staff)
- `CANCELLED` (Cancelled by user/system)

### Recharge Statuses
- `REQUESTED`
- `PAYMENT_PENDING` (Waiting for customer payment)
- `PAYMENT_VERIFIED` (Payment received by FlexiTaka)
- `RECHARGE_PROCESSING` (Top-up balance being delivered)
- `COMPLETED` (Airtime delivered to customer)
- `PAYMENT_FAILED` (Customer payment failed)
- `REJECTED` (Recharge failed/rejected)
- `CANCELLED` (Cancelled)

### Payout / Payment Methods
- `BKASH`
- `NAGAD`
- `BANK`

## 5. Endpoints Reference

### A. Guest Session
- **`POST /api/v1/guest/session`**
  - Response:
    ```json
    {
      "guest_session_id": "FT-G-37393163",
      "session_token": "eyJhbGciOi...",
      "expires_at": "2026-10-19T17:03:13.002Z"
    }
    ```
- **`GET /api/v1/guest/session`**
  - Headers: `X-Guest-Session-ID: FT-G-37393163`

### B. Authentication (Optional Account)
- **`POST /api/v1/auth/request-otp`**
  - Body: `{"phone": "01712345678"}`
  - Response: `{"success": true, "message": "OTP sent successfully", "phone": "01712345678", "expires_in_seconds": 300}`
- **`POST /api/v1/auth/verify-otp`**
  - Body: `{"phone": "01712345678", "otp": "123456"}`
  - Response: `{"access_token": "...", "token_type": "bearer", "user_id": "FT-U-001", "phone": "01712345678", "role": "USER"}`

### C. Operators
- **`GET /api/v1/operators`**
  - Response:
    ```json
    {
      "success": true,
      "operators": [
        {
          "operator_code": "GP",
          "name": "Grameenphone",
          "display_name": "Grameenphone (GP)",
          "status": "ACTIVE",
          "logo_key": "operators/gp.png",
          "supported_services": ["CASH_OUT", "RECHARGE"]
        }
      ]
    }
    ```

### D. Pricing Quotes
- **`POST /api/v1/pricing/cashout-quote`**
  - Body: `{"operator_code": "GP", "amount_bdt": "1000.00"}`
  - Response:
    ```json
    {
      "operator_code": "GP",
      "source_amount_bdt": "1000.00",
      "source_amount_poisha": 100000,
      "platform_fee_rate": "20.00",
      "platform_fee_amount_bdt": "200.00",
      "platform_fee_amount_poisha": 20000,
      "payout_amount_bdt": "800.00",
      "payout_amount_poisha": 80000,
      "currency": "BDT",
      "pricing_rule_version": 1
    }
    ```
- **`POST /api/v1/pricing/recharge-quote`**
  - Body: `{"operator_code": "ROBI", "recharge_amount_bdt": "1000.00"}`
  - Response:
    ```json
    {
      "operator_code": "ROBI",
      "recharge_amount_bdt": "1000.00",
      "recharge_amount_poisha": 100000,
      "discount_rate": "5.00",
      "discount_amount_bdt": "50.00",
      "discount_amount_poisha": 5000,
      "customer_pay_amount_bdt": "950.00",
      "customer_pay_amount_poisha": 95000,
      "currency": "BDT",
      "pricing_rule_version": 1
    }
    ```

### E. Cash Out Orders
- **`POST /api/v1/cashout/orders`**
  - Headers: `Idempotency-Key`, `X-Guest-Session-ID` (if guest), or `Authorization: Bearer <token>`
  - Body:
    ```json
    {
      "operator_code": "GP",
      "source_mobile_number": "01712345678",
      "amount_bdt": "1000.00",
      "payout_method": "BKASH",
      "payout_account": "01911223344"
    }
    ```
  - Response:
    ```json
    {
      "order_id": "FT-108249",
      "status": "WAITING_FOR_TRANSFER",
      "operator_code": "GP",
      "source_mobile_number": "01712345678",
      "source_amount_bdt": "1000.00",
      "payout_amount_bdt": "800.00",
      "receiving_mobile_number": "01711000001",
      "receiving_sim_label": "GP Primary Receiving SIM #1",
      "tracking_token": "a4f89b...",
      "created_at": "2026-09-19T17:00:00Z"
    }
    ```
- **`POST /api/v1/cashout/orders/{order_id}/confirm-transfer`**
  - Body: `{"transfer_reference": "TRX-123456"}`
- **`POST /api/v1/cashout/orders/{order_id}/proof`**
  - Multipart file upload (`file: screenshot.png/jpeg`)

### F. Recharge Orders
- **`POST /api/v1/recharge/orders`**
  - Body: `{"operator_code": "ROBI", "recharge_mobile_number": "01812345678", "recharge_amount_bdt": "1000.00"}`
- **`POST /api/v1/payments`**
  - Body:
    ```json
    {
      "order_id": "FT-108250",
      "method": "BKASH",
      "amount_bdt": "950.00",
      "payer_reference": "01812345678",
      "transaction_reference": "BKASH-TRX-998877"
    }
    ```

### G. Order Tracking & History
- **`GET /api/v1/orders`** (Lists user/guest orders)
- **`GET /api/v1/orders/{order_id}?tracking_token={token}`** (Full timeline and details)
